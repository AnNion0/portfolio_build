떡잎냠냠

AI 기반 개인 맞춤 식단 코칭 서비스

프로젝트 개요

사용자가 회원가입/로그인을 통해 개인 식단을 기록, 관리하고 음식 검색으로 손쉽게 식단에 음식을 추가할 수 있는 개인 맞춤 식단 코칭 서비스입니다. 식단 분석, 기간 리포트, 그래프 시각화와 AI 코멘트/추천을 제공해 일상적인 식습관 개선을 돕습니다.

  • 프로젝트명: 떡잎냠냠
  • 기간: 2025.05.22 ~ 2025.05.28
  • 팀 구성: 3명 (각 회원관리, 식단, 분석 및 추천 기능 수행)
  • 역할: 풀스택(프론트, 백엔드) — 식단 CRUD, 음식 검색

기술 스택

Vue 3 Vite Pinia Axios Spring Boot MySQL MyBatis

서비스 주요 화면

주요 기능

  • 회원관리
    • 아이디 중복 검증 후 회원가입
    • JWT 발급 및 토큰 기반 인증
    • 계정 조회 및 수정
  • 식단
    • 기간별 목록 조회
    • 음식 키워드 자동검색
    • 식단 상세/등록/수정/삭제
  • 식단 분석 & 추천
    • 영양 합계 및 비율 시각화
    • 최근 7일 등 기간별 조회
    • AI 코멘트 및 개인화 추천

나의 역할

  • 식단 CRUD 전담: 기간(시작일~종료일)으로 식단 목록 조회, 상세 보기, 새 식단 등록, 기존 식단 수정, 삭제까지 한 흐름으로 구현하고 화면, API 양쪽에서 입력값 검증 처리
  • 음식 검색: 이름 입력 시 자동완성 목록 표시, 입력이 멈춘 뒤에만 검색 요청이 나가도록 처리해 불필요한 호출 감소. 카테고리를 먼저 고른 뒤 검색해 결과 후보를 줄이는 방식으로 검색 부담 완화
  • UI, 상태 관리: Vue 3와 Pinia로 식단 작성, 수정 화면의 입력값, 목록, 검색 결과 등을 한곳에서 관리하고 식단 추가/편집 화면을 구조적으로 나누어 비슷한 UI를 재사용하기 쉽게 구성
  • 백엔드 연동: 로그인 후 받은 토큰을 API 요청마다 자동으로 붙이고 Spring Boot REST API와 요청, 응답 형식(DTO)을 맞춤
  • 데이터 계층: MyBatis로 식단, 식단에 담긴 음식 조회, 저장용 SQL 매핑 작성

핵심 성과

  • 식단 기록 경험 개선: 식단 저장, 수정 후 별도 새로고침 없이 목록, 대시보드(주간 칼로리, 최근 식단 등)가 바로 갱신되도록 연동
  • 검색 효율 향상: 짧은 시간 연속 입력에도 검색 요청이 과하게 나가지 않게 하고 카테고리로 범위를 좁힌 뒤 이름으로 찾아 결과량 감소
  • 안정성 확보: 날짜, 음식 미선정, 같은 음식 중복 추가, 지원하지 않는 단위 선택 등은 화면에서 선제 차단. 서버에서 요청 데이터 일부 검증 처리
  • 유지보수성 향상: 식단 관련 API 호출과 화면 상태를 Pinia 스토어 한곳에 모아 컴포넌트는 표시에 집중하도록 정리

기술적 도전과 해결

대규모 음식 데이터 검색 지연

  • 원인 분석: 음식 데이터가 약 14만 건 규모인데 이름만으로 넓게 조회해 매 요청마다 검색 후보가 과다해지고 응답, 화면 갱신 부담이 커짐
  • 해결 방법: 음식 테이블에 분류(카테고리) 컬럼을 추가해 음식마다 분류를 저장하고 카테고리와 키워드를 함께 받는 음식 검색 API로 변경. MyBatis에서는 조건부 WHERE로 조회 범위를 줄이고 Vue 식단 작성, 수정 화면에서는 카테고리 선택과 입력 디바운스로 서버 호출 빈도를 낮춤
  • 결과: 카테고리 적용 시 검색 후보군을 전체 대비 약 80% 축소하여 체감 조회 속도와 자동완성 사용성 개선

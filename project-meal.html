냠냠코치 (떡잎냠냠)

프로젝트 개요

사용자가 회원가입/로그인을 통해 개인 식단을 기록·관리하고 음식 검색으로 손쉽게 식단에 음식을 추가할 수 있는 개인 맞춤 식단 코칭 서비스입니다. 식단 분석·기간 리포트·그래프 시각화와 AI 코멘트/추천을 제공해 일상적인 식습관 개선을 돕습니다.

  • 프로젝트명: 떡잎냠냠 (AI 기반 개인 맞춤 식단 코칭 서비스)
  • 기간: 2025.05.22 ~ 2025.05.28
  • 팀 구성: 3명 (각 회원관리, 식단, 분석 및 추천 기능 수행)

기술 스택

  • Frontend: Vue 3, Vite, Pinia, Axios
  • Backend: Spring Boot
  • Database: MySQL, MyBatis

서비스 주요 화면

주요 기능

  • 회원관리
    • 가입/로그인: 가입 폼·처리(중복검증), 로그인 폼·처리(HttpSession.loginUserId, /diets/list)
    • 계정 조회/수정: 상세 조회, 수정 폼, 수정 반영 후 /user/detail
    • 세션/탈퇴: 로그아웃(세션 무효화), 회원 삭제 후 메인(/) 이동
  • 식단
    • 목록/검색: 기간별 식단 목록 조회, 음식 키워드 자동검색(AJAX)
    • 상세/등록: 식단 상세 보기, 날짜·식사 타입·메모 입력 후 음식 추가·등록
    • 수정/삭제: 식단/음식 목록 수정·저장, 상세·목록 화면에서 삭제
  • 식단 분석 & 추천
    • 영양 합/비율: 열량·탄단지 총합, 대시보드 시각화
    • 비교/기간: 최근 동일 식사 비교 리포트, 최근 7일/임의 기간 필터링
    • AI 코칭: 분석 코멘트 및 개인화 추천

나의 역할

  • 식단 CRUD 전담: 목록(기간 필터)·상세·등록·수정·삭제 전체 플로우 구현, 예외/유효성 처리
  • 음식 검색(AJAX): 키워드 기반 자동완성/선택, 비동기 요청 최적화(디바운스·중복요청 취소)
  • UI/상태관리: Vue 3 + Pinia로 상태 모델링, 등록/수정 폼 컴포넌트화 및 재사용성 확보
  • 백엔드 연동: Axios 인터셉터로 공통 에러/세션 처리, Spring Boot API와 DTO 스키마 정렬
  • 데이터 계층 협업: MyBatis 매퍼(페이징·정렬·조건검색) 정의 및 쿼리 성능 점검

핵심 성과

  • 식단 기록 경험 개선: 등록→목록 반영까지 단계 축소 및 폼 UX 정비로 입력/수정 흐름 간소화
  • 검색 효율 향상: 디바운스·중복요청 취소 적용으로 불필요 호출 감소, 키워드 검색 체감 속도 개선
  • 안정성 확보: 예외/유효성 검증과 단위 테스트로 엣지 케이스(빈 날짜, 중복 음식 등) 오류 방지
  • 유지보수성 향상: Pinia 스토어/서비스 모듈 분리로 컴포넌트 의존성 최소화 및 재사용 확대

기술적 도전과 해결

문제 1 — 검색 요청 폭주로 인한 응답 지연

  • 원인: 입력마다 즉시 호출되어 서버에 짧은 간격의 중복 요청 다발
  • 해결: 입력 디바운스(예: 200~300ms)와 이전 요청 취소 토큰 적용, 결과 캐싱으로 재호출 축소

문제 2 — 날짜 범위·페이지네이션 혼합 시 쿼리 일관성

  • 원인: 기간 조건과 정렬/오프셋 조합에 따라 누락·중복 행 발생 가능
  • 해결: MyBatis 매퍼에서 정렬 기준 고정(날짜↓, id 보조키), count 쿼리 분리, 경계값 테스트 추가

문제 3 — 등록/수정 시 데이터 무결성

  • 원인: 식단-음식 다건 입력 중 일부 실패 시 부분만 반영될 위험
  • 해결: 트랜잭션 범위 지정으로 원자성 보장, 서버측 유효성(날짜/타입/칼로리 범위) 선검증

사용한 기술 스택

  • Frontend: Vue 3, Vite, Pinia, Axios
  • Backend: Spring Boot
  • Database: MySQL, MyBatis

Moduru

프로젝트 개요

여행 일정 동시 편집 서비스 MODURU를 개발하여 친구들과 실시간 장소 공유·투표· AI 추천 일정/동선 반영이 가능한 실시간 여행 일정 협업 플랫폼을 구축했습니다. WebSocket(STOMP+SockJS)·Redux 기반의 실시간 협업, Drag & Drop 편집, 지도 시각화, 리뷰·마이페이지 기능을 제공합니다.

  • 프로젝트명: MODURU (실시간 여행 일정 협업 서비스)
  • 기간: 2025.07.14 ~ 2025.08.18
  • 팀 구성: 6명 (프론트엔드 2, 백엔드 2, AI 1, 인프라 1)

기술 스택

  • Frontend: React 18, Redux Toolkit, Vite, Axios, WebSocket(STOMP + SockJS)
  • Backend: Java 17, Spring Boot 3.1.6, Spring Data JPA + QueryDSL, Spring Security + JWT, Spring WebSocket
  • DB/Storage: PostgreSQL, Redis(Pub/Sub, Cache), Elasticsearch, Docker Compose
  • Infra/Etc: AWS EC2, S3, Nginx(리버스 프록시/SSL), LiveKit(SFU), Docker, Gradle

서비스 주요 화면

주요 기능

  • AI 기반 맞춤 여행 일정 생성
    • AI 추천장소, AI 일정 자동 구성, AI 최적 동선 추천
  • 동행자 실시간 협업 기능
    • 행 추가, 희망 장소 공유, 장소 투표, 장소 좋아요
  • 지도 기반 장소 확인 및 일정 시각화
    • 지도 마커 표시, 좋아요 장소 시각화, 일정표 작성/미리보기
  • 유저 주도 일정 편집 및 공유
    • Drag & Drop 일정 편집, 일정 내보내기, 여행 지역 재설정
  • 개인 정보 공간 제공
    • MY 트레블 스페이스, 좋아요 목록, 작성 리뷰, 개인정보

  • 일정 Drag & Drop UI: 직관적인 일정 편집 인터페이스 구현
  • 희망 장소 공유 기능: 실시간 WebSocket 연동으로 협업 반영
  • 일정 동시 편집 기능: Redux + WebSocket 기반 실시간 상태 동기화
  • 추천 기능 UI/UX: AI 일정/경로 추천 결과 실시간으로 상태 공유

핵심 성과

  • 실시간 동기화 품질 향상: 자동 재연결·큐잉·구독 최적화로 동기화 성공률 60% → 90% 개선
  • 체감 성능 개선: Drag & Drop 반영 속도 1.5초 → 0.4초 단축(−73%), 과도 트래픽 억제
  • 협업 UX 완성도: 희망 장소 공유·투표·좋아요가 보드/지도에 실시간 반영되는 협업 경험 구현
  • AI 추천 활용성 증대: 일정·경로 추천 결과를 카드/보드에 매핑하여 즉시 편집 가능

도전 과제와 해결 과정

문제 1: 실시간 협업 중 웹소켓 연결 끊김 및 메시지 유실

  • 원인 분석: STOMP 연결이 불안정할 때 재연결 로직이 없고, 발행된 메시지가 클라이언트에 반영되지 않는 경우 발생
  • 내 행동(해결 방법): 프론트엔드에 자동 재연결 로직과 메시지 큐잉 처리를 직접 구현하고, Redux 반영 순서를 조정, 구독 시점 변경
  • 결과: 협업 동기화 성공률 60% → 90% 개선

문제 2: 일정 Drag & Drop UI 반영 지연

  • 원인 분석: Drag 이벤트 발생 시 Redux와 WebSocket 수신이 동시에 상태를 갱신하면서 동일 변경이 중복 렌더링으로 반영되어 화면 갱신 속도가 늦어졌고, Drag 이벤트가 과도하게 발행되면서 WebSocket 트래픽 폭주가 발생함
  • 내 행동(해결 방법):
    • schedulePublishMiddleware를 구현하여 Drag 관련 액션만 감지
    • WebSocket 수신 액션에는 fromWs 플래그를 적용해 재발행 차단 → 중복 렌더링 제거
    • Drag 발행 이벤트는 150ms 디바운스 + 직전 payload 비교를 적용해 동일·빈번한 발행을 1회로 압축
  • 결과:
    • Drag & Drop 반영 속도 1.5초 → 0.4초 단축(−73%)
    • 불필요한 트래픽 감소 및 반응 속도 개선으로 베타테스트 만족도 90% 이상 확보

문제 3: 일정/경로 추천 결과 UI 반영 어려움

  • 원인 분석: AI 서버 응답 데이터 구조가 복잡해 Redux 상태와 UI 간 매핑 과정에서 일관성 깨짐
  • 내 행동(해결 방법): aiScheduleSlice, aiRouteSlice를 직접 설계하여 추천 결과 구조화, 카드형 UI와 Drag & Drop 보드에 매핑되도록 컴포넌트 구현
  • 결과: AI 추천 일정을 즉시 확인·편집 가능해짐

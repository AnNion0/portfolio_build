Moduru

실시간 여행 일정 협업 웹 서비스

프로젝트 개요

여행 일정 동시 편집 서비스 MODURU를 개발하여 친구들과 실시간 장소 공유, 투표, AI 추천 일정/동선 반영이 가능한 실시간 여행 일정 협업 플랫폼을 구축했습니다. WebSocket(STOMP+SockJS), Redux 기반의 실시간 협업, Drag & Drop 편집, 지도 시각화, 리뷰, 마이페이지 기능을 제공합니다.

  • 프로젝트명: MODURU (실시간 여행 일정 협업 서비스)
  • 기간: 2025.07.14 ~ 2025.08.18
  • 팀 구성: 6명 (프론트엔드 2, 백엔드 2, AI 1, 인프라 1)
  • 역할: 팀장, 프론트엔드

기술 스택 (프론트엔드 · 본인 사용)

React 18 Redux Toolkit JavaScript Vite Axios WebSocket(STOMP+SockJS) CSS Tailwind CSS

서비스 주요 화면

주요 기능

  • AI 기반 맞춤 여행 일정 생성
    • AI 추천장소, AI 일정 자동 구성, AI 최적 동선 추천
  • 동행자 실시간 협업 기능
    • 행 추가, 희망 장소 공유, 장소 투표, 장소 좋아요
  • 지도 기반 장소 확인 및 일정 시각화
    • 지도 마커 표시, 좋아요 장소 시각화, 일정표 작성/미리보기
  • 유저 주도 일정 편집 및 공유
    • Drag & Drop 일정 편집, 일정 내보내기, 여행 지역 재설정
  • 개인 정보 공간 제공
    • MY 트레블 스페이스, 좋아요 목록, 작성 리뷰, 개인정보

나의 역할

  • 팀장 및 프론트엔드: Jira 기반 일정 관리 및 팀 회의 주도. 프론트엔드에서 실시간 동기화 화면 구현
  • Redux 상태 관리 설계 및 WebSocket(STOMP) 연동 로직 개발 → 사용자 동기화 체감 속도 개선
  • 일정 Drag & Drop UI: 직관적인 일정 편집 인터페이스 구현
  • 희망 장소 공유 기능: 실시간 WebSocket 연동으로 협업 반영
  • 일정 동시 편집 기능: Redux + WebSocket 기반 실시간 상태 동기화
  • 추천 기능 UI/UX: AI 일정/경로 추천 결과 실시간으로 상태 공유

핵심 성과

  • 재연결, 동기화 안정성: WebSocket 연결 관리, 구독 재설정, 발행 큐로 끊김, 재연결 구간에서도 일정 변경이 누락되지 않도록 정리해 재연결 상황에서 반영 안정성을 높임
  • 과도 발행, 트래픽 억제: 일정 동기화 발행 미들웨어(디바운스, 동일 payload 생략, 수신 메시지 재발행 차단)로 같은 날짜에 대해 약 10회 발생하던 발행 요청을 1회 수준으로 줄여 중복 WebSocket 트래픽 약 90% 감소를 확인
  • 협업 UX 완성도: 희망 장소 공유, 투표, 좋아요가 보드/지도에 실시간 반영되는 협업 경험 구현
  • AI 추천 활용성 증대: 일정, 경로 추천 결과를 카드/보드에 매핑하여 즉시 편집 가능

기술적 도전과 해결

1. WebSocket 끊김, 재연결 시 동기화 누락

  • 문제: 재연결 이후 구독 복구, 발행 타이밍 불일치로 다른 사용자의 일정 변경이 화면에 반영되지 않음
  • 해결: 끊김 시 기존 구독 정리 후 재연결 시 전체 구독 재설정. 미전송 발행 요청은 큐에 저장했다가 재연결 후 순차 전송
  • 결과: 재연결 구간에서도 일정 변경 누락 없이 안정적 동기화 확보

2. Drag & Drop 연속 변경으로 전송 과다 누적

  • 문제: 같은 날짜에 대한 연속 편집이 짧은 시간 내 반복 발생하면서 전송 요청, 상태 갱신이 과도하게 누적되어 화면 반응 저하
  • 해결: 동기화 발행 미들웨어 설계. 디바운스로 연속 변경을 하나로 압축하고 동일 payload 재전송 생략, 수신 메시지 재발행 차단으로 동기화 루프 방지
  • 결과: 같은 날짜에 대해 약 10회 → 1회 수준으로 줄여 중복 WebSocket 트래픽 약 90% 감소

3. AI 추천 결과 UI 매핑 어려움

  • 문제: AI 서버 응답 구조가 복잡해 Redux 상태와 UI 간 매핑에서 일관성 깨짐
  • 해결: aiScheduleSlice, aiRouteSlice를 설계해 추천 결과를 구조화하고 카드형 UI, Drag & Drop 보드에 매핑되도록 컴포넌트 구현
  • 결과: AI 추천 일정을 즉시 확인, 편집 가능

Wallet Slot

슬롯 기반 AI 예산 관리 서비스

프로젝트 개요

추가 통장 개설 없이 하나의 계좌 안에서 지출 목적별 슬롯을 생성하고 관리할 수 있는 AI 기반 예산 관리 플랫폼입니다. 거래내역 분석과 LLM 기반 슬롯 분류를 통해 소비 패턴을 자동 분석하고 예산 편성과 지출 관리를 지원했습니다.

  • 기간: 2025.08.25 ~ 2025.09.29
  • 팀 구성: 6명 (FE 3 / BE 2 / DE 1)
  • 역할: 데이터 엔지니어 (DE)

기술 스택

  • Python, pandas, MySQL, Spring Boot, LLM
Python pandas MySQL Spring Boot LLM

서비스 주요 화면 ① — 시나리오 #1~2

계정을 만들고, 실제 지출이 있는 계좌를 안전하게 연결하는 구간입니다. 회원가입·본인 확인(1원 인증)으로 최소한의 신원을 확보한 뒤, 마이데이터로 금융사 계좌를 불러와 서비스에서 쓸 대표 계좌를 고릅니다. 이후 슬롯 추천·대시보드는 모두 이 계좌의 거래를 기준으로 동작합니다.

1. 회원가입

앱 진입 후 약관·정보 입력, 휴대폰 1원 인증으로 연락처를 확인하고, 비밀번호·푸시 알림 동의까지 마치면 가입이 완료됩니다.

  • 회원가입
  • 휴대폰 인증 (1원 인증)
  • 비밀번호 설정 및 푸시 알림 동의
  • 회원가입 완료

2. 마이데이터 연동

마이데이터 인증 흐름을 거쳐 은행·카드 계좌를 불러오고, 예산·슬롯에 쓸 연동 계좌와 메인(대표) 계좌를 선택합니다.

  • 마이데이터 연동 화면
  • 금융기관에서 계좌 가져오기
  • 대표 계좌 선택

서비스 주요 화면 ② — 시나리오 #3~끝

슬롯을 잡고 나면 본격적인 예산 운영 단계입니다. 거래 내역을 바탕으로 AI가 슬롯(지출 목적 통)을 추천·확정하고, 대시보드에서 슬롯별 지출을 봅니다. 결제가 들어오면 자동 분류·예산 초과를 푸시로 알리고, 한 건의 영수증을 OCR로 쪼개 넣을 수 있으며, 쌓인 소비는 AI 리포트로 요약해 볼 수 있습니다. 화면 수가 많아 #3 이후를 한 블록으로 묶었습니다.

3. 슬롯 리스트 확정

기준일을 정하면 그 날짜를 축으로 슬롯 목록·금액 편성·소비 리포트가 같이 움직입니다. 분석에 쓸 거래 기간과 추천 기준을 정한 뒤 추천을 받고, 이름·비율을 손봐 최종 확정합니다.

  • 슬롯 추천 화면
  • 기준일 선택 — 슬롯 리스트·금액 편성·소비 리포트 등의 기준 날짜
  • 거래내역 분석 기간 및 슬롯 추천 기준 결정 후 추천
  • 추천받은 슬롯 수정 및 확정

4. 대시보드

확정한 슬롯 기준으로 한눈에 잔액·지출 흐름을 보는 화면입니다. 슬롯별로 얼마 썼는지 비교하기 좋습니다.

  • 슬롯별 지출 현황 확인

5. 푸시 알림

백그라운드에서 슬롯 매칭·예산 검사가 끝나면 사용자에게 알려 줍니다. 자동 분류가 끝났는지, 한도를 넘었는지 빠르게 인지할 수 있습니다.

  • 지출 내역 자동 슬롯 분류 알림
  • 예산 초과 알림

6. OCR 금액 나누기

한 번에 여러 품목이 묶인 결제(예: 다이소)를 영수증 이미지로 읽어, 품목별 금액을 나눈 뒤 슬롯에 반영합니다.

  • OCR로 상품명·금액 추출
  • 해당 슬롯에서 금액 차감·분할

7. 소비 리포트

기준일이 지나면 소비 패턴을 AI가 짧게 요약합니다. 알림 탭에서 리포트 생성 알림을 누르면 상세 화면으로 이어집니다.

  • 기준일에 맞춰 소비 리포트 생성
  • 소비 데이터 AI 분석·요약
  • 알림 탭에서 리포트 알림 확인 후 상세 화면 진입

소비 리포트 상세 화면 GIF·스크린샷은 추가 시 이 구간에 연결할 수 있습니다.

시연 흐름 요약 (① + ② 전체)

① 회원가입 → 마이데이터 연동 → 서비스에 연동할 계좌 선택 → 메인 계좌 선택 → ② 슬롯 추천 → 슬롯 리스트 확정 → 대시보드 진입 → (결제 내역 발생) 지출이 자동 슬롯 분류되었다는 푸시 알림 → (예산 초과 지출 발생) 예산 초과 푸시 알림 → 다이소 등 결제 건을 선택해 OCR로 결제 내역 분리 → (AI 소비 리포트 발생) 알림 탭에서 리포트 알림을 눌러 소비 리포트 화면으로 진입

주요 기능

AI 기반 슬롯 예산 관리

  • 거래내역 기반 AI 예산안 추천
  • 슬롯 리스트 자동 생성 및 편집
  • 다음 달 예산 재편성 추천

지출 자동 분류

  • LLM 기반 슬롯 자동 매칭
  • 미분류 거래 발생 시 푸시/배너 알림

계좌 연동 및 소비 분석

  • 마이데이터 기반 계좌 연동
  • 슬롯별 지출 현황 대시보드 제공
  • 소비 패턴 분석 및 AI 소비 리포트 제공

거래 기록 관리

  • 슬롯 이동 및 금액 분할
  • OCR 기반 영수증 처리
  • 더치페이 기능 지원

담당 역할

  • 대용량 가맹점 데이터 적재 파이프라인: 약 1,347만 건의 원본 데이터를 정규화하여 슬롯 분류 단위 기준 약 535만 엔티티로 축소, ThreadPoolExecutor 기반 병렬 처리 및 대량 INSERT 배치 최적화, INSERT ON DUPLICATE KEY 기반 업서트로 재실행 시 데이터 일관성 확보
  • 분산 데이터 통합 자동화: 마켓/법인/인허가/포털/기업DB 등 5개 원본 소스를 단일 Staging 구조로 통합, 지역별 폴더·파일명 자동 스캔 기반 CSV 병합 스크립트, 소스·지역별 스캔·매핑 규칙을 코드로 고정해 컬럼 구조 차이 대응, 소스별 접두·연번 기반 가맹점 통합 식별자 부여, 업종 DB 생성 및 가맹점–업종 다대다 매핑 자동화
  • LLM 슬롯 분류 파이프라인: Staging → Targets → LLM → Service DB 흐름 설계, Targets(후보 집합) 기반 분류 대상 선별 및 OpenAI 자동 분류, 최종 슬롯 판정을 서비스 DB에 적재·업서트해 조회·자동 매칭에 활용
  • 서비스 UX 설계: 마이데이터 기관 선택부터 슬롯 온보딩까지 화면 단위 사용자 플로우 설계, 가입·금융 연동·슬롯·리포트 구간별 필수·선택 동의 UX 설계 및 구현

핵심 성과

  • 데이터 적재 효율화: 약 1,347만 건 → 슬롯 분류 단위 약 535만 엔티티로 축소, 병렬 적재·일관성 확보
  • 분산 데이터 통합 자동화: 5개 원본 데이터 구조를 단일 Staging 병합 파이프라인으로 통합
  • LLM 비용 최적화: Targets 기반 후보 선별로 호출량 감소, 전량 호출 대비 비용·레이트 리스크 완화
  • 데이터 안정성: idempotent 업서트로 재실행 시에도 데이터 일관성 유지

기술적 도전과 해결

1. 대용량 CSV 적재 지연 및 슬롯 분류 단위 문제

  • 문제: 통합 스테이징 약 1,347만 건 처리 시 적재 지연, 슬롯 분류용 가맹점 단위 불명확으로 분류 효율 저하
  • 해결: 상호명 정규화로 슬롯 분류 단위 엔티티 구성, drop_duplicates 기반 중복 제거, ThreadPoolExecutor 병렬 처리 및 멀티 VALUES INSERT 배치 최적화
  • 결과: 약 1,347만 건 → 약 535만 엔티티로 축소, 적재 속도 개선 및 분류 단위 명확화

2. 분산 데이터 구조 불일치 통합 문제

  • 문제: 소스별 폴더 구조·컬럼명 상이로 자동 병합 어려움
  • 해결: 소스·지역별 스캔·매핑 규칙을 코드로 고정, 파일별 매핑 자동화, 소스별 접두·연번 기반 통합 식별자 부여
  • 결과: 5개 원본 타입을 단일 Staging 파이프라인으로 통합 완료

3. LLM 기반 슬롯 분류 비용 문제

  • 문제: 수백만 건 규모를 전부 LLM에 넣을 경우 호출·비용·지연 과다
  • 해결: Targets(후보 집합) 단계에서 룰·유사도 기반 선별 후 OpenAI 분류만 수행, 결과를 서비스 DB에 적재·업서트
  • 결과: 전량 호출 대비 호출 건수 감소로 비용·레이트 리스크 완화, 서비스 조회·자동 분류에 활용 가능한 형태로 관리

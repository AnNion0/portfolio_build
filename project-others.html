기후변화에 따른 외래식물 분포 예측 연구

연구 개요

본 연구는 기후변화 시나리오(RCP 4.5 / 8.5)에 따른 외래식물의 서식지 변화를 예측하기 위해 MaxEnt 모델을 활용한 분포 예측 및 생태적 위험 분석을 수행했습니다. 국내 주요 기후 요인(강수량, 기온, 토양)을 반영하여 향후 확산 가능 지역을 시각적으로 제시했습니다.

연구 결과 시각화

연구 주요 내용

  • 5년간 수집된 생태조사 데이터의 전처리 및 GIS 좌표 정규화
  • MaxEnt 기반 서식 분포 예측 및 AUC 지표(≥0.8) 검증
  • RCP 시나리오별 외래식물 확산 위험도 분석 및 시각화
  • 국립식량과학원 협업 데이터베이스 구축 기여

사용 기술

Python QGIS Pandas MaxEnt

연구 성과

  • 외래식물 분포 예측 정확도 AUC 0.82 달성
  • 논문 게재 및 환경연구 학술대회 구두 발표
  • 기후변화 대응 생태정보 관리 DB 구축 기반 제공

지속가능 소비를 위한 개인 맞춤형 금융 데이터 서비스

프로젝트 개요

“Wallet Slot”은 개인의 소비 데이터를 자동 분석하여 생활 속 소비 습관을 인식하고 개선할 수 있도록 돕는 사회문제 해결형 데이터 서비스입니다. 환경·소비 균형, 청년층 금융 습관 개선을 목표로 개발했습니다.

서비스 주요 화면

주요 기능

  • AI 기반 소비 슬롯 자동 분류 및 추천
  • 소비 리포트 및 예산 비율 시각화
  • 지속가능 소비 습관 개선 알림 기능

기술 스택

Spring Boot Vue.js MySQL Python LLM API

나의 역할

  • ETL 파이프라인 및 LLM 슬롯 분류 로직 설계
  • 소비 데이터 정제·DB 연동 자동화 스크립트 개발
  • 슬롯 기반 소비 리포트 시각화 구현

핵심 성과

  • 소비 데이터 1,400만 건 정제 및 안정적 적재 성공
  • 룰+LLM 하이브리드 분류 정확도 85% 달성
  • 개인화된 소비 인사이트 리포트 완성

기술적 도전과 해결

도전: 대용량 데이터 처리 시 메모리 초과 및 중복 분류 문제

해결: 멀티-VALUES 배치 업서트 및 체크포인트 기반 병렬 로직 적용으로 안정적인 대량 적재를 실현하고, LLM confidence 기반 폴백 처리로 분류 품질을 높였습니다.

SoundCake - 금융 데이터 파이프라인 자동화

대규모 금융 거래 데이터를 처리하기 위한 ETL 자동화 파이프라인을 구축하고, LLM 기반 소비 카테고리 분류 및 데이터 검증 로직을 설계했습니다.

주요 기능

  • 데이터 무결성 검증 및 에러 리포트 생성

기술 스택

Python MySQL FastAPI Threading

기후변화 기반 외래식물 분포 예측 연구

MaxEnt 기반 외래식물 서식지 예측 및 토종 식물 영향 분석

연구 개요

기후변화 시나리오(RCP4.5 / RCP8.5) 환경에서 외래·교란 식물의 잠재 서식지를 예측하고, 주요 환경 결정요인을 분석한 연구입니다. 출현자료 기반 MaxEnt 모델을 활용해 전국 단위 위험지도를 구축하고, 침입종이 토종 식물 적합도에 미치는 영향을 공간적으로 분석했습니다.

  • 기간: 2023.10 ~ 2024.11
  • 역할: 제1저자
  • 논문 게재: 한국데이터정보과학회지 (2024)

기술 스택

Python elapid scikit-learn NumPy Pandas GeoPandas Rasterio Matplotlib QGIS

연구 목적

  • 잠재 서식지 예측: 기후변화 시나리오(RCP4.5 / RCP8.5) 기반 외래식물 분포 예측
  • 환경 변수 분석: 외래식물 분포에 영향을 주는 핵심 환경 변수 분석
  • 공간적 영향 분석: 침입종이 토종 식물 적합도에 미치는 공간적 영향 분석
  • 정책 지원: 우선 관리구역 선정 및 복원 정책 수립 지원

연구 수행 내용

데이터 구성

가시상추, 미국쑥부쟁이 2016~2021년 출현 좌표 활용, 한반도 전역 무작위 배경 데이터 10,000점 샘플링, RCP4.5 / RCP8.5 기반 생물기후(BIO) 변수 생성, 다중공선성 제거(VIF ≤ 10) 및 변수 군집화 수행

모델링

Python elapid 기반 MaxEnt 모델 구축, 정규화 배수 1, 선형 특징(linear feature) 적용, 5-Fold 교차검증 기반 일반화 성능 평가

변수 해석 및 분석

Permutation Importance 기반 변수 중요도 분석, PDP(Partial Dependence Plot) 기반 환경 변수 반응 분석, 공선성 완화를 위한 VIF 및 변수 군집화 수행

분포 예측 분석

  • 가시상추: RCP8.5 환경에서 적합도 확대, 수도권·서해안·경상권 중심 확장 가능성 도출
  • 미국쑥부쟁이: 남해·동해·서해 해안축 중심 확장 경향 확인
  • 종간 영향: 토종 쑥부쟁이 적합도 감소 지역 식별

핵심 성과

  • 높은 모델 성능: 모든 모델에서 AUC 0.8 이상, 잠재 서식지 예측에 활용 가능한 판별력 확인
  • 시나리오별 위험지도: 외래식물 2종에 대해 시나리오별(2030s / 2050s) 위험지도 구축 완료
  • 핵심 환경 요인: 기후변화 기반 결정요인 도출 및 PDP 기반 반응 분석 수행
  • 정책 활용: 우선 관리 및 복원 지역 선정에 활용 가능한 분석 근거 제공

SoundCake

프로젝트 개요

카페 매장을 위한 B2B 음악 추천 서비스로, 매장의 콘셉트·객층·시간대를 반영해 최적의 플레이리스트를 추천합니다. LLM을 활용한 태그 문맥 이해로 추천 정확도를 높이고, 매장 전용 AI 생성 플레이리스트를 제공하여 브랜드 이미지 강화와 운영 효율을 동시에 지원합니다.

  • 프로젝트명: SoundCake
  • 기간: 2024.07.07 ~ 2024.08.06
  • 팀 구성: 6명 (PL 1, 기획 2, 데이터 1, 모델링 1, 웹개발 1)

기술 스택

  • Frontend: React
  • Backend: Node.js
  • Data/ML: Python, Jupyter
  • Database: MySQL (Amazon RDS)
  • 협업/도구: Figma, Notion, Google Drive, VS Code

서비스 주요 화면

주요 기능

  • 컨텍스트 기반 입력 수집
    • 매장 정보(입지·분위기·영업시간)와 고객 정보(성별/연령대)를 UI에서 입력
    • 현재 위치의 날씨(비/눈/맑음 등)를 자동 반영
  • 플레이리스트 추천(기존)
    • 플레이리스트-태그 데이터를 중심으로 SentenceTransformer 임베딩과 AutoEncoder 잠재공간 유사도로 후보 탐색
    • 태그 교집합 기준으로 기존 플레이리스트 추천
  • 플레이리스트 생성(신규)
    • 태그 조건으로 곡을 새로 조합해 매장 전용 플레이리스트 생성
    • GPT를 활용한 플레이리스트 제목 자동 생성
  • 플레이리스트 커버 이미지 생성
    • 선택한 분위기·날씨와 플레이리스트 태그 기반 커버 이미지 자동 생성
  • Spotify 재생 연동
    • Spotify 계정 인증(OAuth) 및 API/Web Playback으로 음악 재생
    • SoundCake 내부에서 플레이리스트 생성·관리

나의 역할

  • 데이터 설계·수집: 카페 메타 태그(분위기/시간대/객층) 설계 및 데이터 수집·정제 파이프라인 구축
  • 추천 모델 구현: scikit-learn 기반 콘텐츠/태그 기반 추천 베이스라인 구현 및 오프라인 평가
  • LLM 활용: 태그 문맥 강화(동의어/상·하위 개념 매핑) 실험 및 점수 앙상블
  • API 연동: 매장주 콘솔 프로토타입 협업 및 추천 API 연동 PoC

핵심 성과

  • 추천 품질 향상: 태그 문맥 강화로 내부 만족도 지표 개선(파일럿 테스트 기준)
  • 운영 효율화: 추천 파이프라인 자동화로 매장 선곡 운영 시간 절감
  • 비즈니스 확장: 데이터 상품화 시나리오(익명화 메타데이터 라이선스) 정립

기술적 도전과 해결

문제 — 모호/중복 태그로 인한 추천 품질 저하 및 콜드스타트

  • 원인: 동일 의미의 태그가 다르게 표현되거나, 신규 매장/곡 데이터 부족
  • 해결: LLM 기반 태그 정규화·문맥 보정 + scikit-learn 콘텐츠 점수 앙상블
  • 결과: 모호 태그 구간의 품질 안정화, 신규 매장/곡 콜드스타트 대응력 향상

사용한 기술 스택

  • Data/ML: Python, Jupyter, scikit-learn
Python Jupyter scikit-learn
